🎬 StreamFlix Content Analytics
StreamFlix Content Analytics is a data analytics project developed as part of my Data Analyst Internship at Internmo.

The project analyzes a fictional subscription-based video streaming platform, StreamFlix, to understand subscriber trends, content engagement, revenue performance, ratings, and viewing behavior.

The analysis was performed using Python, Pandas, NumPy, SQL, and Power BI to transform raw data into meaningful business insights and interactive dashboards.

Key Findings

Some key findings from the analysis include:

Standard is the most popular subscription plan.
The United States has the highest number of subscribers.
StreamFlix subscribers are distributed across multiple countries, genres, and devices.
Subscription plans contribute differently to overall revenue.
Viewing activity and ratings provide useful indicators of content engagement.
Positive ratings can be analyzed to identify content that performs well with viewers.

Note: The dataset is fictional and created for learning and portfolio purposes.

Conclusion

The StreamFlix Content Analytics project demonstrates an end-to-end data analytics workflow, starting from data preparation and exploratory analysis to SQL-based analysis and interactive Power BI dashboards.

The project focuses on converting raw data into meaningful business insights that can support data-driven decision-making.
